============================================================
1. TONG QUAN HE THONG
============================================================

IN-OUT Tracker la ung dung web quan ly thu chi ca nhan theo thang/ngay.
Nguoi dung dang nhap bang Google, sau do co the:
- Xem dashboard thu, chi, so du rong theo thang va theo ngay.
- Them giao dich nhanh bang van ban tu do, vi du: "pho 45k; cafe 25k".
- Cap nhat, xoa giao dich da ghi nhan.
- Loc va tim kiem giao dich theo loai va tu khoa.
- Quan ly cac khoan dong/hop dong/hoa don dinh ky theo ngay den han.
- Xac nhan da dong hoac hoan tac trang thai da dong cua khoan dong.
- Cau hinh ngay nhan luong va luong du kien.
- Xem du tru cac khoan can dong trong ky luong hien tai.
- Xem bieu do phan tich xu huong thu/chi, chi theo danh muc va tong quan thang.

Cong nghe trong ma nguon:
- Frontend: Next.js App Router, React, TypeScript.
- UI: Tailwind CSS, cac component Button, Card, Dialog, Tabs, Input, Textarea.
- Backend: Next.js API Routes.
- Database: MongoDB thong qua Mongoose.
- Validation: Zod.
- Dang nhap: Google OAuth/OpenID Connect thong qua google-auth-library.
- Bieu do: Recharts.
- Thong bao: Sonner toast.

Ghi chu pham vi:
- He thong khong co vai tro admin, khong co chia se du lieu giua nhieu nguoi dung.
- Du lieu duoc tach theo userId lay tu phien dang nhap Google.
- He thong khong tich hop ngan hang, vi dien tu hay payment gateway. Viec "da dong" hoa don/khoan dong la ghi nhan thu cong.
- Tao giao dich moi hien tai duoc thuc hien bang Quick input. Khong thay form tao giao dich thu cong rieng trong UI, nhung co form sua chi tiet giao dich da ton tai.

2. TAC NHAN, HE THONG BEN NGOAI VA PHAM VI
============================================================

Tac nhan chinh:
1. Nguoi dung
   - Ca nhan su dung he thong de theo doi thu chi.
   - Phai dang nhap Google truoc khi truy cap cac man hinh nghiep vu.

Tac nhan phu/he thong ben ngoai:
1. Google OAuth/OpenID Provider
   - Cung cap man hinh dang nhap Google.
   - Tra ve authorization code va id_token.
   - Cung cap thong tin dinh danh: googleId, email, name, picture.

2. MongoDB
   - Luu user, phien nghiep vu dang o dang token cookie da ky, giao dich, khoan dong va cau hinh.
   - Duoc truy cap qua Mongoose model/repository.

Thanh phan noi bo quan trong:
- AuthProvider/AuthGate/AuthStatus: quan ly trang thai dang nhap o client.
- Dashboard page: tai giao dich, khoan dong, cai dat va hien thi tong quan.
- Bills page: CRUD khoan dong va cap nhat trang thai da dong.
- Settings page: cap nhat ngay luong va luong du kien.
- API routes: nhan request, kiem tra session, validate input, goi repository.
- Domain services: quickParse, payrollWindow, reserveInWindow, analytics.
- Repository: transactionsRepo, billsRepo, settingsRepo, usersRepo.

4. API VA LOP DU LIEU
============================================================

Bang API chinh:

1. GET /api/auth/me
   - Muc dich: kiem tra phien dang nhap.
   - Dau vao: cookie inout_session.
   - Dau ra: { user } hoac 401 { user: null }.

2. GET /api/auth/google?returnTo=/duong-dan
   - Muc dich: bat dau dang nhap Google.
   - Dau vao: returnTo.
   - Dau ra: redirect sang Google OAuth, set cookie state va returnTo.

3. GET /api/auth/google/callback?code=...&state=...
   - Muc dich: xu ly callback Google.
   - Dau vao: code, state, OAuth cookies.
   - Dau ra: redirect ve returnTo, set cookie session; neu loi redirect /?auth=error.

4. POST /api/auth/logout
   - Muc dich: dang xuat.
   - Dau vao: session cookie.
   - Dau ra: { ok: true }, clear session cookie.

5. GET /api/transactions?month=YYYY-MM
   - Muc dich: lay giao dich theo thang.
   - Dau vao: month.
   - Dau ra: { items: TransactionDTO[] }.

6. POST /api/transactions/quick
   - Muc dich: them giao dich nhanh tu text.
   - Dau vao: { date: YYYY-MM-DD, raw: string }.
   - Dau ra: { added: number, skipped: string[] }.

7. PATCH /api/transactions/:id
   - Muc dich: sua giao dich.
   - Dau vao: TransactionInput hop le.
   - Dau ra: { id } hoac loi 400/401/404.

8. DELETE /api/transactions/:id
   - Muc dich: xoa giao dich.
   - Dau vao: transaction id.
   - Dau ra: { id } hoac loi 401/404.

9. GET /api/bills
   - Muc dich: lay danh sach khoan dong.
   - Dau vao: session cookie.
   - Dau ra: { items: BillDTO[] }.

10. POST /api/bills
    - Muc dich: them hoac sua khoan dong.
    - Dau vao: BillInput, neu co id thi sua, khong co id thi them moi.
    - Dau ra: { id } hoac loi 400/401.

11. DELETE /api/bills/:id
    - Muc dich: xoa khoan dong.
    - Dau vao: bill id.
    - Dau ra: { id } hoac loi 401/404.

12. PATCH /api/bills/:id/pay
    - Muc dich: xac nhan da dong.
    - Dau vao: { paidAt: YYYY-MM-DD, paidAmount?: number, paidNote?: string }.
    - Dau ra: { id } hoac loi 400/401/404.

13. PATCH /api/bills/:id/unpay
    - Muc dich: hoan tac trang thai da dong.
    - Dau vao: bill id.
    - Dau ra: { id } hoac loi 401/404.

14. PATCH /api/bills/:id/paid
    - Muc dich: toggle trang thai da dong don gian bang boolean.
    - Dau vao: { paid: boolean }.
    - Dau ra: { id }. UI hien tai chu yeu dung /pay va /unpay.

15. GET /api/settings
    - Muc dich: lay cau hinh ky luong cua nguoi dung.
    - Dau ra: { paydayDay, salaryExpected }. Neu chua co thi tao mac dinh.

16. POST /api/settings
    - Muc dich: cap nhat cau hinh ky luong.
    - Dau vao: { paydayDay: 1..31, salaryExpected >= 0 }.
    - Dau ra: { paydayDay, salaryExpected }.

Bang du lieu chinh:

1. User
   - googleId: string, unique.
   - email: string.
   - name?: string.
   - picture?: string.
   - createdAt: Date.
   - lastLoginAt: Date.

2. Transaction
   - userId: string.
   - date: Date.
   - type: "expense" hoac "income".
   - amount: number > 0.
   - category: string.
   - desc: string.
   - source?: string.
   - method?: string.
   - account?: string.
   - note?: string.
   - createdAt: Date.

3. Bill
   - userId: string.
   - name: string.
   - amount: number > 0.
   - dueDay: number 1..31.
   - group?: string.
   - start?: Date.
   - end?: Date.
   - note?: string.
   - paid: boolean.
   - paidAt?: Date.
   - paidAmount?: number.
   - paidNote?: string.

4. Settings
   - userId: string, unique.
   - paydayDay: number 1..31, mac dinh 25.
   - salaryExpected: number >= 0, mac dinh 0.

------------------------------------------------------------
UC01 - Dang nhap bang Google
------------------------------------------------------------

Muc tieu:
- Cho phep nguoi dung xac thuc bang tai khoan Google va tao phien su dung he thong.

Tac nhan chinh:
- Nguoi dung.

Tac nhan phu/ben thu ba:
- Google OAuth/OpenID Provider.
- MongoDB luu hoac cap nhat user.

Tien dieu kien:
- GOOGLE_CLIENT_ID va GOOGLE_CLIENT_SECRET duoc cau hinh.
- AUTH_SECRET hoac GOOGLE_CLIENT_SECRET co the dung de ky session.

Kich hoat:
- Nguoi dung bam "Dang nhap" hoac bi AuthGate yeu cau dang nhap.

Du lieu vao:
- returnTo: duong dan muon quay lai sau khi dang nhap.
- Google authorization code va state o callback.

Luong chinh:
1. Nguoi dung bam Dang nhap.
2. He thong tao state ngau nhien, luu state va returnTo vao cookie tam thoi.
3. He thong redirect sang Google OAuth.
4. Nguoi dung chon tai khoan Google va cap quyen.
5. Google redirect ve /api/auth/google/callback voi code va state.
6. He thong so sanh state trong request voi state trong cookie.
7. He thong doi code lay token va verify id_token.
8. He thong lay googleId, email, name, picture.
9. He thong upsert User vao MongoDB.
10. He thong tao session token da ky va set cookie inout_session.
11. He thong xoa cookie OAuth tam thoi va redirect ve returnTo.

Luong thay the/ngoai le:
- Sai/thieu code hoac state: redirect ve /?auth=error.
- Google khong tra id_token hoac email chua xac minh: redirect ve /?auth=error.
- Thieu bien moi truong Google: login that bai.

Dau ra/hau dieu kien:
- User duoc luu/cap nhat trong collection users.
- Cookie inout_session duoc set, thoi han 30 ngay.
- Nguoi dung co the truy cap cac chuc nang can xac thuc.

Phu thuoc:
- GoogleAuthService, SessionService, UserRepository, MongoDB.

API/lop lien quan:
- GET /api/auth/google
- GET /api/auth/google/callback
- src/lib/auth/google.ts
- src/lib/auth/session.ts
- src/lib/repo/usersRepo.ts

Activity Diagram:
@startuml
start
:Nguoi dung bam Dang nhap;
:Tao OAuth state;
:Luu state va returnTo vao cookie;
:Redirect sang Google OAuth;
:Nguoi dung xac thuc tren Google;
:Google redirect ve callback;
if (code/state hop le?) then (Co)
  :Doi code lay token;
  :Verify id_token;
  if (Thong tin Google hop le?) then (Co)
    :Upsert user vao MongoDB;
    :Tao session token da ky;
    :Set session cookie;
    :Xoa OAuth cookies;
    :Redirect ve returnTo;
  else (Khong)
    :Redirect /?auth=error;
  endif
else (Khong)
  :Redirect /?auth=error;
endif
stop
@enduml

------------------------------------------------------------
UC02 - Dang xuat
------------------------------------------------------------

Muc tieu:
- Ket thuc phien dang nhap tren trinh duyet hien tai.

Tac nhan chinh:
- Nguoi dung.

Tac nhan phu/ben thu ba:
- Khong co dich vu ben ngoai. He thong chi xoa cookie phien.

Tien dieu kien:
- Nguoi dung dang co session hoac UI dang hien trang thai da dang nhap.

Kich hoat:
- Nguoi dung bam "Dang xuat".

Du lieu vao:
- Cookie inout_session hien tai.

Luong chinh:
1. Nguoi dung bam Dang xuat.
2. AuthProvider goi POST /api/auth/logout.
3. API tra { ok: true } va set cookie inout_session rong voi maxAge = 0.
4. Client set user = null.
5. AuthGate hien lai man hinh yeu cau dang nhap.

Luong thay the/ngoai le:
- Neu request that bai, UI van co the can refresh lai trang de doc lai session.

Dau ra/hau dieu kien:
- Session cookie bi xoa.
- Nguoi dung khong con truy cap duoc dashboard/bills/settings neu chua dang nhap lai.

Phu thuoc:
- SessionService, AuthProvider.

API/lop lien quan:
- POST /api/auth/logout
- src/components/auth/AuthProvider.tsx
- src/lib/auth/session.ts

Activity Diagram:
@startuml
start
:Nguoi dung bam Dang xuat;
:Client goi POST /api/auth/logout;
:Server clear session cookie;
:Server tra {ok:true};
:Client dat user = null;
:AuthGate hien man hinh dang nhap;
stop
@enduml

UC03 - Xem Dashboard theo thang/ngay
------------------------------------------------------------

Muc tieu:
- Hien thi lich thang, tong thu/chi/rong, danh sach giao dich cua ngay duoc chon, cac khoan can dong trong ky luong.

Tac nhan chinh:
- Nguoi dung da dang nhap.

Tac nhan phu/ben thu ba:
- MongoDB luu transaction, bill, settings.

Tien dieu kien:
- Session hop le.

UC13 - Xem du tru cac khoan can dong trong ky luong

Muc tieu:

8. SummaryCards hien "Du tru truoc luong toi".
9. BillsInWindow hien tung khoan can dong va ngay den han.

Luong thay the/ngoai le:
- Khong co bill phu hop: hien "Khong co khoan can dong".

Dau ra/hau dieu kien:

7.3 Cac rang buoc nghiep vu quan trong

Rang buoc xac thuc:
- Moi API nghiep vu ve transactions, bills, settings deu can session hop le.
- Session token la payload base64url + HMAC SHA-256 signature.
- Session het han sau 30 ngay.
- OAuth state cookie het han sau 10 phut.

Rang buoc giao dich:
- date phai dung YYYY-MM-DD.
- type chi duoc la expense hoac income.
- amount phai lon hon 0.
- category va desc bat buoc.
- Giao dich luu date o dau ngay bang startOfDay.
- Truy van theo thang dung khoang [startOfMonth, startOfNextMonth).
- Moi cap nhat/xoa deu loc theo _id va userId de tranh truy cap du lieu user khac.

Rang buoc quick input:
- Raw co the tach theo xuong dong, ";" hoac "；".
- Dong bat dau bang "+" hoac "thu:" duoc xem la thu nhap.
- Neu khong co category, expense mac dinh "An uong", income mac dinh "Luong".
- Category co the nam trong cap ngoac vuong o dau dong, vi du [Di lai].
- Source co the nam sau ky tu "@", vi du @Grab.
- So tien hop le la so duong, co the ket thuc bang "k".
- Dong khong co so tien hop le se bi skipped.

Rang buoc khoan dong:
- name bat buoc.
- amount phai lon hon 0.
- dueDay la so nguyen tu 1 den 31.
- Neu co start va end thi start <= end.
- Khi paid = true, bill bi bo qua khi tinh reserveInWindow.
- Khi unpay, he thong xoa paidAt, paidAmount, paidNote.

Rang buoc ky luong va du tru:
- paydayDay duoc clamp theo so ngay cua thang. Vi du paydayDay = 31 trong thang 2 se tro thanh ngay cuoi thang 2.
- payrollWindow gom lastPay va nextPay dua tren ngay hien tai.
- Bill duoc tinh vao du tru neu chua paid, dueDate nam trong khoang lastPay < dueDate <= nextPay va khong nam ngoai start/end.
- Du/Thieu = salaryExpected - reserveTotal.
